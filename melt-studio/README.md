# Melt Studio for Cursor

Melt Studio's skills (the development pipeline and audits, the PM suite and company checks such as
the work-laptop endpoint check) for Cursor. It only works with an **@meltstudio.co** login.

This plugin is generated from the Melt skills and holds only a stub per skill. The instructions
themselves are served by Melt's `meltctl` MCP server (`https://api.meltctl.meltstudio.co/mcp`), which this plugin
configures, so they stay up to date without reinstalling.

## Sign in

1. Install the plugin. Cursor adds the `meltctl` MCP server.
2. Open Cursor Settings → MCP, find `meltctl` and sign in. A browser window opens: use your
   @meltstudio.co Google account.

## Run a skill

Ask for it in the agent chat (for example "run the endpoint check") or type its name, such as
`/melt-company-verify-endpoint`. The agent loads the instructions from `meltctl` and follows them.
