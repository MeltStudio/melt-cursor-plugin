# Melt Studio for Cursor

Melt Studio's skills (development pipeline, audits, PM suite and company checks) for Cursor.

This plugin only holds short stubs and the connector config. The skills themselves load at runtime
from Melt's meltctl MCP server, which requires an `@meltstudio.co` Google login, so the plugin does
nothing for anyone outside Melt.

Generated and mirrored from Melt's private developer-tools repo. Don't edit it here: every sync
overwrites it. See [melt-studio/README.md](melt-studio/README.md) for setup.
